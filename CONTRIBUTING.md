# Contribution Guidelines

This is a curated list, not an index of every Flask repository. When in doubt, leave it out.

## Pull requests

- Open one pull request per suggestion.
- Use this format: `- [Name](https://example.com) - Description.`
- Start the description with an uppercase letter and end it with a period.
- Add new items at the bottom of the matching section unless the section is alphabetical.
- Check spelling and grammar, and remove trailing whitespace.
- Explain why the project is awesome, not only what it does.
- Do not add paid courses or one-off blog posts. Tutorials should be a series or an official guide.

## Quality bar

Projects on the main list should meet all of the following:

- Works as documented.
- Supports Python 3.10+ and a current Flask 3.x release, or documents the supported range.
- Actively maintained: commits in the last 12 months, or maintainers still respond to issues and pull requests.
- Not archived, deprecated, or superseded. Put historical entries in [archived.md](archived.md).
- Has documentation. Tests are expected where practical.

If a listed project later fails this bar, open an issue or a pull request to move it to `archived.md` or replace it with the successor.
