## Superseded

- [Flask-RESTPlus](https://github.com/noirbizarre/flask-restplus) - Replaced by [Flask-RESTX](https://github.com/python-restx/flask-restx).
- [Flask-Security (mattupstate)](https://github.com/pallets-eco/flask-security-3.0) - Archived. Use [Flask-Security](https://github.com/pallets-eco/flask-security).
- [Flask-SSLify](https://github.com/kennethreitz/flask-sslify) - Unmaintained. Use [Flask-Talisman](https://github.com/wntrblm/flask-talisman).
- [Flask-OpenTracing](https://github.com/opentracing-contrib/python-flask) - OpenTracing is retired. Use [OpenTelemetry](https://github.com/open-telemetry/opentelemetry-python-contrib).
- [Miserlou/Zappa](https://github.com/Miserlou/Zappa) - Original project stalled. Community fork is [zappa/Zappa](https://github.com/zappa/Zappa).
